# Jenkins CI/CD Pipelines

A collection of Jenkins pipelines built to automate different parts of the software delivery process.

These projects cover practical CI/CD workflows, from source code checkout and application builds to containerization, testing, code quality, security scanning, image publishing, and deployment.

## What You'll Find Here

The pipelines in this repository explore different Jenkins automation workflows, including:

- Continuous Integration
- Application builds
- Automated testing
- Docker image builds
- Docker Hub and container registry integration
- Code quality analysis with SonarQube
- Security and vulnerability scanning
- Artifact and image versioning
- Automated deployments
- Kubernetes deployments
- Jenkins and GitHub integration
- CI/CD pipeline automation
- Jenkins Pipeline as Code

The projects may use different tools depending on the workflow being demonstrated.

## Technologies

The collection may include:

- Jenkins
- Jenkinsfile / Declarative Pipeline

- Docker
